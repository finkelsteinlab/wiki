## 1. Materials

Make sure we have:

- 25kDA PMMA from [Polymer Source Inc](http://www.biopolymersource.com/), Part number: [P8443C-MMA](http://www.biopolymersource.com/dataSheet/P8443C-MMA.pdf) (dead link)
- 495K PMMA A6 solution (495K M.W. 6% in anisole; part \#495PMMA A6) from [MicroChem](http://microchem.com/) <a class="pdf-copy" href="/wiki/media/archive/microchem-com.pdf" title="Archived PDF copy">PDF</a>[495PMMA-data-sheet](/wiki/media/recipes/495pmma_data_sheet.pdf)
- Anisole from Sigma-Aldrich (part number [123226-1L](http://www.sigmaaldrich.com/catalog/product/sial/123226?lang=en&region=US) <a class="pdf-copy" href="/wiki/media/archive/www-sigmaaldrich-com-catalog-product-sial-123226.pdf" title="Archived PDF copy">PDF</a>)
- PMMA Developer (MIBK:IPA=1:3) from [MicroChem](http://microchem.com/) <a class="pdf-copy" href="/wiki/media/archive/microchem-com.pdf" title="Archived PDF copy">PDF</a> (part \#M/I 1:3)

## 2. 25 kDa PMMA solution

1. Dissolve the 25kDA PMMA in anisole to 3% (w/w). Typically I use magnetic stirring overnight.
2. Filter the PMMA solution with syringe filter.

## 3. 495 kDa PMMA solution

1. Dilute the 495K PMMA A6 solution (6% anisole) to 1.5% in anisole.
2. Filter the PMMA solution with syringe filter.
