## 1. Overview

<img src="/wiki/media/instruments/mastercyclerpro.jpg" width="150" alt="|Mastercycler" /> The PCR machine is the Mastercycler Pro. We have two machines linked in tandem.

## 2. General Instructions

1. Turn on **both** machines. Switch is in the back.
2. Login as guest.
3. Access or create necessary program.
4. Open lid and place samples inside. Close lid. Lock lid.
5. Run program. Wait. To pause push stop, to abort push abort, to change anything while running program push exit.
