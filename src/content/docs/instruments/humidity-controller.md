## 1. Overview

We have three Humidity/Temperature controllers in our microscope room (3.422F). These are important to maintain constant conditions in the room for each microscope.

All three units have been set to the same parameters as follows:

The Temperature has been set to 70 degrees.

The Humidity set point is 50 percent. The Humidity Alarm set point is 35% - 70% so the alarm will only sound when the humidity travels outside of those parameters. In the event the alarm sounds, you can press the Alarm Mute button on the thermostat face to silence the audible alarm for 15 minute. No further action is required since the system will automatically adjust to return to the programmed set point.

The HVAC technician advised that since all three systems are in the same room, it is possible for them to counteract each other (example one unit may be humidifying while the other may be dehumidifying). Take that into account if you need to alter the temperature conditions for your experiments.

Finally, report any continued issues to Greg or Ilya so they can determine if a service call is required.
