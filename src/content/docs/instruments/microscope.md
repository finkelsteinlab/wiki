## 1. Microscope filter set up

Light incoming to the microscope is cleaned up by a variety of filters on the light path to the CCD camera. The light goes through the first filter cube has only one 490 long pass (lp) filter. The bottom filter cube contains the dichroic splitter that separates the light signal into the red and the green channel as well as a few more clean up filters. If the filter cube set up is permanently changed, please inform Max so he can update this page. The following figures display the current microscope 2 set up (left) and the previous setup (right).
