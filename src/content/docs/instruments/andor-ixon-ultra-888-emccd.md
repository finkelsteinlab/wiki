## 1. Overview

<img src="/wiki/media/instruments/andor_ixon.png" width="200" alt="andor_ixon.png" /> The Andor iXon 888 is designed for our specific applications and to be compatible with both our microscope and the software we use to run our experiments. Key features of this camera include: (1) highly sensitive scientific-grade camera, (2) a large field of view to permit two-color fluorescence experiments using one camera, (3) compatibility with the software systems used to run our experiments.
