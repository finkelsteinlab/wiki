## 1. Sequencer IDs

Each sequencer at the GSAF has an ID number that is included in the FASTQ data at the beginning of each read line.

| ID     | Name      |
|--------|-----------|
| M05354 | Valentina |
| M02288 | Sally     |
| M01012 | Thor      |

Take this randomly-selected read as an example:

    M02288:34:000000000-BB7NK:1:2101:12233:1901

It was sequenced on Sally and the ID number on the physical MiSeq chip is BB7NK.
