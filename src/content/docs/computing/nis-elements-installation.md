## 1. Installation

1. When setting up installation, click “Local Options.” This will install additional elements such as “Macro Panel” and “Export as TIFF.”

   <img src="/wiki/media/code/localoption.png" width="200" alt="localoption.png" />

2. Select the proper cameras:

   <img src="/wiki/media/code/andor.png" width="200" alt="andor.png" />

3. Select the Microscope:

   <img src="/wiki/media/code/nikon.png" width="200" alt="nikon.png" />

## 2. Modifying an existing installation

If NIS Elements is already installed, it can be modified by going to “Start” bar –> “Add or Remove Programs” –> search “NIS” and select NIS Elements. Select to “Modify.”

<img src="/wiki/media/code/modify.png" width="200" alt="modify.png" />

## 3. Optical Configurations

When setting up Optical Configurations, set the active shutter to “DIA.”
