## 1. Data Processing & Analysis

- [ImageJ](http://rsbweb.nih.gov/ij/download.html) (dead link) - a free, open-source NIH-funded image processing software. ImageJ is written in Java and is extended through a variety of plugins. It is the software of choice for processing microscopy images.
  - [Fiji](http://fiji.sc/wiki/index.php/Fiji) - an extended version of ImageJ with a set of additional plugins. Fiji includes a Python interpreter that allows python scripting of ImageJ.
  - [ImageJ 2](http://developer.imagej.net/) - ImageJ 2.0 development promises to improve an already great package
- [Matlab](http://www.mathworks.com/products/matlab/) - powerful mathematics suite for data analysis
- [Python](http://www.python.org/) - a very easy-to-use programming language with a full suite of numerical methods and science packages. Great, free alternative to writing MatLab code.

## 2. Plasmids, PCR and Cloning

- [ApE](http://biologylabs.utah.edu/jorgensen/wayned/ape/) - a free, cross-platform plasmid editor. Maintained out of University of Utah
- Online tools:
  - [NEB Primer Tm Calculator](http://www.neb.com/nebecomm/tech_reference/TmCalc/Default.asp#.T48e2TJWq4I) <a class="pdf-copy" href="/wiki/media/archive/www-neb-com-nebecomm-tech-reference-tmcalc-default-asp.pdf" title="Archived PDF copy">PDF</a> - recommended for doing PCR with NEB polymerases
  - [Primer3Plus](http://www.bioinformatics.nl/cgi-bin/primer3plus/primer3plus.cgi) - very powerful PCR and sequencing primer design tool
  - [NIH DNAWorks](http://helixweb.nih.gov/dnaworks/) <a class="pdf-copy" href="/wiki/media/archive/helixweb-nih-gov-dnaworks.pdf" title="Archived PDF copy">PDF</a> - Oligo design for gene synthesis.

## 3. Writing Papers

- [Microsoft Word](http://office.microsoft.com/en-us/word/) - I write all manuscripts in MS Word.
- [EndNote](http://www.endnote.com/) - Citation manager for manuscripts written in Word.
- [OriginLab](http://www.originlab.com/) <a class="pdf-copy" href="/wiki/media/archive/www-originlab-com.pdf" title="Archived PDF copy">PDF</a> - Creates publication-quality graphs.
- [PyMol](http://www.pymol.org/) - Publication-quality protein structures.
- [Adobe Illustrator](http://www.adobe.com/products/illustrator.html) - Publication-quality illustrations and figure layouts.
