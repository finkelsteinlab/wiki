## 1. Plasmid Database

Store plasmids in a 1.7 mL centrifuge tube by assigning them a new pIF# in the database, printing out a label, and storing in the appropriate box. Include the concentration of the plasmid on the side of the tube for ease of access.

The database is in the lab's Google Drive.

## 2. Strain Database

Store a strain by mixing 1mL saturated cells in media with 1mL 50% glycerol in a 2mL cryo tube. Flash freeze with liquid nitrogen and store in the appropriate -80 rack. Add to the database.

The database is in the lab's Google Drive.

## 3. Oligo Database

Oligos are stored at 100uM upon receipt, in the IDT tube they arrived in. Resuspend the dried sample in ddI H2O, assign it a new number in the database, print a label, and store in the appropriate box in the -20.

The database is in the lab's Google Drive.

## 4. Racks Database

-80 Freezer Racks. When you make new pellets, protein, or add a new box of any kind, please update this database with the location and contents of the box. When a box is empty, remove the box and update the database to show an empty spot at its previous address.

The database is in the lab's Google Drive.
